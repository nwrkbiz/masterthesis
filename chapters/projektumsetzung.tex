Auch diese Beispiel befindet sich als CMake \cite{cmake} Projekt auf der CD-ROM/DVD und ist unter \textit{Thesis/prototype3} zu finden. Es kann mit folgenden Befehlen 
übersetzt werden. Dazu wird das \textit{SMF\_3P} Verzeichnis benötigt und eine WinCC OA Installation benötigt. \\

SUSE Linux Enterprise 12.5:

\begin{GenericCode}
$ mkdir build
$ cd ./build
$ cmake .. -DSMF_3P=~/SMF_3P -DWINCCOA_INSTALL=C:/Siemens/Automation/WinCC_OA/3.16
$ cmake --build .
\end{GenericCode}

Windows 10:

\begin{GenericCode}
$ mkdir build
$ cd ./build
$ cmake .. -T v140 -A x64 -DSMF_3P=C:/SMF_3P -DWINCCOA_INSTALL=C:/Siemens/Automation/WinCC_OA/3.16
$ cmake --build .
\end{GenericCode}
